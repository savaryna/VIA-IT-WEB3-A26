# WEB3 Assignment 3

## UNO against other players

Implement an UNO game that works in the browser. The game should allow playing against players through a server.

## Requirements

### Must have

- [x] The application must allow playing a round of UNO against 1-3 human opponents
- [x] The play must proceed according to the official UNO rules
- [x] The application must have at least the same features as [Assignment 2](./2.md)
- [x] The application must allow users to identify themselves
- [x] The application must allow users to create a new game
- [x] The application must allow users to join an existing game
- [x] The server must notify the participants in the game every time something happens in the game
- [x] The server must use GraphQL as the communication protocol.

### Should have

- [x] The server should keep track of players and scores in a database (or file)
- [x] The application should implement user registration and login

### Could have

- [x] The application could allow playing an entire game (with score) of UNO against 1-3 human opponents
- [x] If the game is an entire game, the server could allow saving the game after a round and resume it later

## Things to consider

- What is the best way to handle notifications to the client?
- What is the best way to save to database?

## The required code

The client should be implemented using Vue.js. It can be either Options or Composition API but be consistent. If you want to try out server-side rendering, feel free, but it’s not a requirement.

The server should be implemented as a GraphQL server using Apollo Server.
